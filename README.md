Welcome to my interactive personal portfolio! This repository houses a modern, sleek, and highly animated web experience designed to showcase my projects, skills, and journey as a developer.

---

## ✨ Features

- **Immersive Dark Theme**: A deep, aesthetic UI with gradient overlays and neon accents.
- **Fluid Animations**: Meaningful page transitions and micro-interactions powered by `framer-motion`.
- **Dynamic Projects Showcase**: Beautiful bento-grid and card layouts to display my latest tech ventures.
- **Responsive Design**: Built mobile-first to ensure a pristine experience across all screen sizes.
- **Fast & Optimized**: Scaffolded with Vite for lightning-fast HMR and optimized production builds.

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
- **Build Tool**: Vite

## 🏃‍♀️ Running Locally

Want to explore the code or run it on your own machine? It's simple!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SnixPranshi01/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or yarn install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
